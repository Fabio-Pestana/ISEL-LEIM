Para carregar Dados:

1. Inicializar o container de SMI no Docker.
2. Abrir o browser, pesquisar localhost. ir a phpMyAdmin.
3. Criar uma base de dados chamada de NexusWiki.
4. Selecionar NexusWiki, e clicar no botão Importar.
5. Importar ficheiro sql e pressionar no Executar.

Para executar trabalho:

1. Inicializar o container de SMI no Docker.
2. Abrir o browser, pesquisar localhost. ir a Examples SMI.
3. Selecionar a pasta do projeto.
4. Selecionar login.php.
