## Descrição

Trabalhos práticos que abordam conceitos de **eletrónica digital**,
**circuitos combinatórios e sequenciais**, **microprocessadores** e
**sistemas embebidos**, incluindo:

- Funções lógicas e simplificação por mapas de Karnaugh
- Circuitos combinatórios e sequenciais
- Máquinas de estados (ASM) e Flip-Flops JK
- Arquitetura de Harvard e microprocessador ARV
- Protocolo I2C e sensores (temperatura, pressão, humidade)
- Display alfanumérico LCD
- Comunicação série Arduino - Python
- Interface gráfica em Python (Tkinter)
