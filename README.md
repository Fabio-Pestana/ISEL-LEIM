# ISEL-LEIM

Repositório com os **trabalhos práticos, laboratórios e projetos** que desenvolvi ao longo da **Licenciatura em Engenharia Informática e Multimédia (LEIM)** no **Instituto Superior de Engenharia de Lisboa (ISEL)**, entre os anos letivos 2022/23 e 2024/25.

- **Autor:** Fábio Pestana — A50756

Muitos dos trabalhos foram feitos em grupo, os restantes elementos estão identificados no README de cada unidade curricular.

---

## Estrutura

O repositório está organizado por semestre e, dentro de cada um, por unidade curricular (UC). Cada UC tem o seu próprio `README.md` com a descrição, as tecnologias usadas e a estrutura das pastas.

```
ISEL-LEIM/
├── 1º Semestre/    # 2022/23
├── 2º Semestre/    # 2022/23
├── 3ºSemestre/     # 2023/24
├── 4ºSemestre/     # 2023/24
├── 5ºSemestre/     # 2024/25
└── 6ºSemestre/     # 2024/25
```

## Notas

- O `.gitignore` exclui ficheiros gerados e de configuração local: `.gradle/`, `build/`, `out/`, `.idea/`, `bin/`, `target/`, `node_modules/` e `google-services.json`. Os projetos Android que precisem do Firebase exigem o teu próprio `google-services.json`.
- Os detalhes de cada trabalho (autores, docente, estrutura de pastas) estão no `README.md` da respetiva UC.
- Cadeiras sem trabalhos práticos não se encontram neste repositório.
