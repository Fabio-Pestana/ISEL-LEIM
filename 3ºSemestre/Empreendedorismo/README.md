# Empreendedorismo — Projeto

Projeto de **plano de negócio** desenvolvido na unidade curricular **Empreendedorismo** de LEIM,
no **ISEL**, ano letivo 2023/24.

A equipa criou a **Brigid Tales**, um serviço de **audiolivros imersivos** com som binaural 3D,
narração por vários atores e banda sonora original, desenvolvido pela empresa fictícia **Ludik**.
